JPEGView Modern Compilation Guide
*********************************

Requirements:
- Visual Studio 2022 (v143/v144 toolset) with C++20 support
- CMake 3.28+ (or Ninja)
- Windows 10/11 SDK (10.0.22621+)
- Windows Template Library (WTL) submodule (located in deps/WTL-sf)
- Optional: vcpkg for package management (vcpkg.json manifest mode)

Building with CMake:
-------------------
1. Clone submodules:
   git submodule update --init --recursive

2. Configure and build with CMake:
   cmake -B build -S . -DCMAKE_BUILD_TYPE=Release
   cmake --build build --config Release

Building with Visual Studio 2022:
--------------------------------
1. Open src/JPEGView.sln in Visual Studio 2022
2. Select 'Release' and 'x64' configuration
3. Build Solution (Ctrl+Shift+B)
      An #ifdef is used to disable that feature when compiling for standard below C++17

Older solution files have been removed from the source tree.  If you still need them, clone the tag v1.2.45
